# Ideate — 게임 아이디어 리서치 스킬

## Trigger
- "게임 아이디어 줘", "게임 뭐 만들까", "아이디어 줘"
- "트렌드 조사", "인기 게임 분석", "장르 분석"

## Steps

### Step 1: 의도 명확화 게이트 (Clarity Gate)

입력이 충분히 명확하면 **되묻지 말고 바로 Step 2** 로 간다. 아래 6축 중 4개 이상이 정해지면 통과한다.

- 장르·핵심 손맛(탭·스와이프·홀드·퍼즐·타이밍 등)
- 타겟 플레이어와 한 판 길이(세션)
- 플랫폼·시장(한국/글로벌), 화면 방향(기본 세로)
- 차별화 방향 단서
- 수익 모델 방향(보상형 광고 / 전면 광고 / IAP / 유료)
- 아트 방향(미니멀 도형 / imagegen 일러스트 / 공용 에셋)

- `_workspace/spec.md` 가 있으면 `project.*`, `monetization.*`, `ux.*` 와 `*_notes` 로 먼저 채우고 **빈 축만** 묻는다.
- 모자라면 질문 2~4개를 `AskUserQuestion` 으로 한 번에 묻는다(최대 2라운드). "알아서 해" 면 기본값(전체 트렌드, 1인 개발, 한국+글로벌, 세로, 보상형 광고)으로 통과한다.
- `execution.unattended: true` 면 질문 없이 `on_ambiguity` 정책을 따른다.

### Step 2: 트렌드 리서치
- WebSearch 로 App Store·Google Play 게임 차트(장르별 Top Free / Grossing)와 최근 히트 하이퍼캐주얼·하이브리드캐주얼 게임을 조사한다.
- 리뷰에서 반복되는 불만(광고 과다, 반복성, 난이도 곡선)을 모은다.

### Step 3: 경쟁 게임 분석
- 유사 게임 5~10개: 코어 루프, 세션 길이, 리텐션 장치(목표·등급·기록·해금), 수익화 배치, 약점.

### Step 4: 아이디어 도출 (3~5개)
각 아이디어에 담는다.
- 가제, 한줄 설명, 타겟
- **코어 루프**(10초 안에 이해되는 반복 행동)와 한 판 길이
- 리텐션 장치(다시 할 이유)
- 수익화 적합도(보상형 광고 지점, IAP 후보)
- 차별점
- **1인 개발 실현성**: 씬을 코드로 생성(`Generate()`), 결정적 Domain 시뮬레이션으로 테스트 가능한가, 아트는 도형·imagegen·공용 에셋으로 충분한가. 공용 에셋은 `~/works/game-assets/aether/LLM_INDEX.md` 를 먼저 읽고 `search_assets.py` 로 찾는다(워크스페이스 규칙)

### Step 5: 사용자 선택
- 선택·조합 결과를 `_workspace/idea/app-concepts.md` 에 저장한다.
